HTML :
Hyper Text Markup Language , used to give a structure to a web page It contains tags, which is used to add text, images, audios, videos, etc to a webpage

Tag              Name                 Description
<h1>-<h6>,      Headings,        "Defines HTML headings. <h1> is the most important, <h6> the least."
<p>,            Paragraph,        Defines a block of text as a paragraph.
<br>,           Line Break,       Inserts a single line break without starting a new paragraph.
<a>,            Anchor,           Creates a hyperlink to another page or a specific location.
<img>,          Image,            Embeds an image into the document.
<ul>            Unordered List,   Creates a bulleted list of items.
<ol>            Ordered List,     Creates a numbered list of items.
<li>            List Item         Adds a items to a list.
<div>,          Division,         A container used to group block-level elements for styling.
<span>,         Division,         A container used to group inline-level elements for styling.
<a>,            Anchor,           Defines a hyperlink. Use the href attribute to set the destination URL.
<img>,          Image,            Embeds an image. Requires src (source) and alt (alternative text) attributes.
<video>,        Video,            Used to embed video content. Often used with controls to allow play/pause.
<iframe>,       Inline Frame,     Used to embed another document or website inside the current page (like a YouTube video).
